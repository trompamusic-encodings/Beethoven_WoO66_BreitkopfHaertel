# 13 Variations on the Theme „Es war einmal ein alter Mann“ by Dittersdorf (WoO 66) by Ludwig van Beethoven

This repository contains a diplomatic encoding of [13 variations on the theme „Es war einmal ein alter Mann” from the opera „Das rothe Käppchen“ by Dittersdorf, WoO 66 by Ludwig van Beethoven, Breitkopf und Härtel edition, 1862–90. Plate B.175.](https://imslp.org/wiki/Special:ReverseLookup/53040)

No assurances are made regarding the validity or consistency of this encoding or its structure.
